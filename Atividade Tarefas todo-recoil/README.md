# Atividade Lista de Tarefas - todo Recoil 

Aplicação de gerenciamento de tarefas desenvolvida com **React**, **Vite** e **Recoil** como exercício da EBAC para praticar gerenciamento de estado global.

O projeto permite organizar tarefas do dia a dia de forma simples e intuitiva, com uma interface responsiva, cores suaves e cartões de tarefas.

## Funcionalidades

- Adicionar novas tarefas
- Marcar tarefas como concluídas ou pendentes
- Remover tarefas
- Filtrar tarefas por todas, concluídas ou pendentes
- Visualizar a quantidade de tarefas e o progresso de conclusão
- Interface responsiva para diferentes tamanhos de tela

## Conceitos praticados

Durante o desenvolvimento, foram praticados os seguintes conceitos:

- **RecoilRoot:** provedor que disponibiliza o estado global para os componentes da aplicação.
- **Atoms:** estados globais utilizados para armazenar a lista de tarefas e o filtro selecionado.
- **Selector:** estado derivado responsável por retornar a lista de tarefas conforme o filtro ativo.
- **useRecoilState:** hook utilizado para consultar e atualizar átomos.
- **useRecoilValue:** hook utilizado para consultar valores de átomos e seletores.
- **Componentização:** organização da aplicação em componentes reutilizáveis.
- **Responsividade:** adaptação da interface para diferentes tamanhos de tela.


## Sobre a atividade

Exercício desenvolvido para a EBAC com o objetivo de praticar gerenciamento de estado global em React utilizando Recoil, incluindo atoms, selectors e hooks.
