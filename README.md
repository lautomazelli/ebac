# 📚 EBAC — Formação Front-end

Repositório com atividades e projetos desenvolvidos durante minha formação em **Front-end na EBAC**.

Aqui registro minha evolução prática, desde os primeiros passos com HTML, CSS e JavaScript até projetos com frameworks modernos, consumo de APIs e deploy no GitHub Pages.


---

## Tecnologias aplicadas nos projetos

**Core:** HTML5 · CSS3 · JavaScript · Git · GitHub  
**Frameworks CSS:** Bootstrap · Tailwind CSS · Sass  
**Dados:** APIs REST (ViaCEP, JSONBin) · Web Storage (localStorage)  
**Outros:** GitHub Pages · Classes JS (ES6+) · Mobile-first
