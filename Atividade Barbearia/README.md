Landing page desenvolvida para a barbearia fictícia **Estilo Livre**, com o objetivo de criar um site moderno, responsivo e visualmente atrativo utilizando o framework **Bootstrap**.

Projeto desenvolvido no módulo de **Bootstrap** da formação **Front-end da EBAC**, aplicando na prática o sistema de Grid, os componentes prontos e as classes utilitárias do framework.

---

## Sobre o Projeto

A **Estilo Livre** é uma barbearia fictícia que precisava de uma presença digital à altura do seu estilo: moderna, direta e bem apresentada.

O site foi construído como uma **landing page de página única**, organizada em seções que conduzem o visitante da primeira impressão até o contato:

- **Home**: banner de destaque com chamada para ação (CTA);
- **Sobre Nós**: apresentação da barbearia, seu estilo e sua proposta;
- **Serviços**: cards com os serviços oferecidos (corte, barba, hidratação e mais);
- **Depoimentos**: carrossel com comentários de clientes, usando o componente *Carousel* do Bootstrap;
- **Contato**: formulário com campos de nome, e-mail e mensagem.

---

## Tecnologias Utilizadas

- **HTML5**: estrutura semântica do documento;
- **CSS3**: ajustes finos de estilização;
- **Bootstrap**: framework CSS base do projeto:
  - *Grid System* para estruturar todas as seções;
  - *Navbar* responsiva com menu colapsável;
  - *Cards* para a vitrine de serviços;
  - *Carousel* para os depoimentos;
  - *Forms* para o formulário de contato;
  - *Classes utilitárias* para espaçamentos, cores e alinhamentos.

---

## Destaques Técnicos

- **Responsividade completa:** o layout se adapta de desktop a celular usando o Grid System e as media queries do Bootstrap;
- **Menu inteligente:** a Navbar colapsa automaticamente em telas menores, garantindo navegação confortável no mobile;
- **Componentização:** uso de componentes prontos do framework (botões, cards, carousel, formulário) com personalização de tema;
- **Código enxuto:** aproveitando o Bootstrap, o CSS customizado ficou mínimo, o foco ficou em estrutura e composição.

---

## Aprendizados

Este foi meu **primeiro projeto utilizando um framework CSS**, um passo importante depois de construir layouts com CSS puro nos projetos anteriores.

Principais aprendizados:
- Entender a lógica do **Grid System** (linhas, colunas e breakpoints);
- Trabalhar com **componentes prontos** e customizá-los sem "brigar" com o framework;
- Usar **classes utilitárias** para resolver espaçamento e alinhamento de forma rápida e consistente;
- Perceber na prática o ganho de produtividade que um framework traz — sem abrir mão de entender o CSS que existe por trás dele.
