## Sobre o Projeto

A **Agência Criativa Web** é uma Landing Page moderna e 100% responsiva desenvolvida para uma agência de design digital fictícia. 

O objetivo principal deste projeto foi consolidar e aplicar na prática conceitos avançados de **Design Responsivo**, arquiteturas de layout modernas utilizando **Flexbox** e **CSS Grid**, além de implementar interatividade e manipulação do DOM com **JavaScript puro**, sem o uso de frameworks externos.

> *Este projeto foi desenvolvido como parte da formação em Front-end da **EBAC**, com foco rigoroso em boas práticas de UI/UX, performance web e escrita de Clean Code.*

## Funcionalidades 
-  **Layout 100% Responsivo:** Fluidez perfeita entre Desktop, Tablet e Mobile.
-  **Menu Hambúrguer Animado:** Navegação intuitiva para dispositivos móveis com transições suaves em CSS e JS.
-  **Carrosséis Dinâmicos:** Slides de imagens e depoimentos com lógica de navegação e autoplay construída em JavaScript.
-  **Otimização de Performance:** Uso da tag `<img>` com atributo `srcset` para servir imagens adaptativas, reduzindo o tempo de carregamento em dispositivos móveis.
-  **UI/UX Aprimorada:** Implementação de Scroll Suave (Smooth Scrolling) e micro-interações com animações CSS.
-  **Múltiplas Páginas:** Roteamento simples entre a Home (`index.html`) e uma página dedicada de Contato (`contato.html`) com formulário estilizado.

##  Tecnologias Utilizadas

O projeto foi construído utilizando a stack fundamental da Web, explorando seus recursos mais modernos:

| Tecnologia | Destaques de Uso |
| :--- | :--- |
| **HTML5** | Estruturação semântica e acessibilidade. |
| **CSS3** | *Custom Properties* (Variáveis), Flexbox, CSS Grid e Media Queries. |
| **JavaScript** | Orientação a Objetos (Classes), Manipulação do DOM e *Event Listeners*. |
