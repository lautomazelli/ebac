# Atividade de Parquímetro

Interface de parquímetro desenvolvida em aula na formação **Front-end da EBAC**, para praticar **HTML5**, **CSS3** e **JavaScript**.

O projeto apresenta um menu lateral com diversas opções, sendo a funcionalidade principal de cálculo de tempo de estacionamento totalmente implementada e funcional.

![Tela inicial](print1.png)

![Funcionalidade em uso](print2.png)

![Resultado do cálculo](print3.png)

### Tecnologias
- HTML5
- CSS3
- JavaScript

### Como usar
1. Abra o arquivo `index.html` no navegador;
2. O menu lateral apresenta diversas opções de navegação;
3. Na funcionalidade principal, insira o valor desejado ou escolha uma das opções de tempo/valor;
4. Confira as informações e se estiver tudo correto, clique em **Adicionar saldo**;
5. O sistema exibe o valor a ser pago pelo estacionamento, o troco se houver e adiciona o valor ao seu saldo.

### Funcionalidades implementadas
- Adição de tempo/valor de estacionamento (totalmente funcional)
- Layout responsivo e moderno
- Menu lateral com navegação visual
- Validação de entrada de dados

### Observação
As demais opções do menu lateral estão implementadas apenas como **layout/prototipagem**, SEM FUNCIONALIDADE COMPLETA. O foco desta atividade foi a criação da interface visual e implementação da funcionalidade principal.
